## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Rig Builder** | Plan your full skill tree and perk selection before a trial |
| **Synergy Finder** | Highlights perk combinations with strong co-op synergy |
| **Unlock Tracker** | Mark owned upgrades and see what's next in each tree |
| **Build Share** | Export rig builds as a code for teammates to import |
